# Focus_Cube - 自律立方项目

## 项目概述

这是一个基于Arduino+STM32的自律立方项目，用于检测学习环境和提醒用户保持良好的学习习惯。

## 功能特点

- **时间选择**：支持5分钟到60分钟的学习时间设置
- **环境检测**：
  - 人体红外检测：检测用户是否在学习位置
  - 噪音检测：可选择开启/关闭，检测环境噪音
  - 光线检测：可选择开启/关闭，检测环境光照
- **倒计时功能**：精确的学习倒计时
- **智能提醒**：当环境不适合学习时，蜂鸣器发出提醒
- **状态显示**：OLED实时显示当前状态
- **快捷重置**：两个按键同时按可重置到初始状态

## 硬件要求

- STM32开发板（如BLUEPILL_F103C8）
- OLED显示屏（128x64，I2C接口）
- 人体红外传感器（HC-SR501）
- 光照传感器（如光敏电阻模块）
- 噪音传感器（如声音检测模块）
- 蜂鸣器
- 按键（2个）

## 文件结构

- Focus_Cube.ino          - 主程序文件
- SelfDiscipline.h        - 自律立方功能定义
- SelfDiscipline_page.cpp - 功能实现
- SelfDiscipline_draw.cpp - 显示实现
- OLED_Display.h/cpp      - OLED显示驱动
- PinDefines.h            - 硬件引脚定义和参数阈值



## 使用方法

### 1. 启动流程

1. 启动设备后，OLED显示启动画面"Focus_Cube"
2. 进入**时间选择**界面
3. 调整学习时间（按返回键调整，5分钟步进）
4. 按确认键进入**环境检测选择**
5. 选择环境检测模式（按返回键切换：全开→仅光线→仅噪音→关闭→全开）
6. 按确认键开始**倒计时**

### 2. 运行状态

- **倒计时界面**：显示剩余时间和环境状态
  - "状况：学习中"：环境良好
  - "状况：无人"：无人
  - "状况：噪音过大"：噪音大
  - "状况：光线过暗"：光线暗
  - "状况：多种问题"：多种环境问题

### 3. 完成状态

- 倒计时结束后，进入**完成界面**
- 显示"Done! Well Done!"
- 按确认键重新开始
- 按返回键重新设置时间

### 4. 快捷操作

- **同时按下两个按键**：重置到初始状态
- **任意状态**：按返回键可返回上一级或调整设置
- **任意状态**：按确认键可确认选择或进入下一步

## 状态说明

### 系统状态

| 状态 | 说明 |
|------|------|
| STATE_INIT | 初始化状态 |
| STATE_SELECT_TIME | 时间选择 |
| STATE_SELECT_ENV | 环境检测选择 |
| STATE_COUNTING | 倒计时中 |
| STATE_FINISHED | 完成状态 |

### 环境状态

| 状态 | 说明 |
|------|------|
| STATUS_GOOD | 环境良好 |
| STATUS_NO_PERSON | 无人 |
| STATUS_NOISE_HIGH | 噪音大 |
| STATUS_LIGHT_DARK | 光线暗 |
| STATUS_MULTIPLE | 多种问题 |

## 参数调整

在`PinDefines.h`文件中可调整以下参数：

- `LIGHT_MIN`：最小合适光照（默认100）
- `SOUND_THRESHOLD`：噪音阈值（默认500）
- `WARNING_DURATION`：警告持续时间（默认500ms）

## 编译和上传

1. 在Arduino IDE中打开`Focus_Cube.ino`
2. 安装必要的库：
   - Adafruit GFX Library
   - Adafruit SSD1306
   - Adafruit BusIO
3. 选择STM32开发板（如BLUEPILL_F103C8）
4. 编译并上传代码

## 开发板配置

- 开发板：Generic STM32F103C series
- 变体：BluePill F103C8
- 上传方法：Serial

## 注意事项

1. 确保OLED地址正确（默认0x3C）
2. 传感器模块的灵敏度可能需要调整
3. 蜂鸣器音量可通过串联电阻调整
4. 按键已配置为内部上拉输入，无需外部上拉电阻
5. 建议使用3.3V电源供电
