## ✅ **这个5文件方案的优势**

### **1. 数量适中，易于管理**
- 3个核心逻辑文件 + 1个硬件驱动 + 1个头文件
- 不会像10+个文件那样混乱
- 也不会像2个文件那样臃肿

### **2. 职责分明**
```
Focus_Cube.ino          - 系统入口，按键调度，主循环协调
SelfDiscipline_page.cpp - 纯业务逻辑（5个状态的处理）
SelfDiscipline_draw.cpp - 纯显示逻辑（5个界面的绘制）
OLED_Display.cpp/h      - 硬件抽象层（与OLED硬件交互）
PinDefines.h           - 配置和定义（跨文件共享）
```

### **3. 编译效率高**
- 修改显示逻辑只需重编 `SelfDiscipline_draw.cpp`
- 修改业务逻辑只需重编 `SelfDiscipline_page.cpp`
- 修改硬件驱动只需重编 `OLED_Display.cpp`

### **4. 适合STM32项目**
- 头文件依赖简单，减少编译错误
- 内存占用可预测
- 适合Arduino IDE的项目结构

---

## 🚀 **启动流程（STATE_INIT）**

1. **上电启动**：
   - 显示启动画面：“Focus Cube”
   - 下方显示“Press to start”
   - 底部显示一个小计时器（00:00），表示系统运行时间

2. **等待用户操作**：
   - 此时系统处于空闲状态
   - 按下 **确认键** 进入下一个状态
   - 两个按键同时按下：**无操作**（因为还在启动界面）

---

## ⏰ **时间选择界面（STATE_SELECT_TIME）**

1. **界面显示**：
   - 标题：“Time”
   - 中间显示当前选择的时间（如 25:00）
   - 底部提示：“OK” 和 “ADJ”

2. **操作逻辑**：
   - **返回/调整键**：每次按下增加5分钟
     - 5 → 10 → 15 → ... → 60 → 回到5（循环）
   - **确认键**：确认选择的时间，进入下一个状态
   - **双键同时按下**：**退出到启动界面**

---

## 🛡 **环境检测选择（STATE_SELECT_ENV）**

1. **界面显示**：
   - 标题：“Env”
   - 中间显示当前选择的检测模式
   - 底部提示：“START” 和 “MODE”

2. **检测模式选择**（循环切换）：
   ```
   全开（Light+Noise）
   → 仅光线（Only Light）
   → 仅噪音（Only Noise）
   → 全关（Disabled）
   → 回到全开
   ```

3. **操作逻辑**：
   - **返回/调整键**：切换检测模式
   - **确认键**：确认选择，**开始倒计时学习**
   - **双键同时按下**：**退出到启动界面**

---

## 📚 **倒计时学习状态（STATE_COUNTING）**

1. **界面显示**：
   - 顶部大字体显示：剩余时间（MM:SS）
   - 底部显示环境状况：
     - “状况：学习中”（良好）
     - “状况：无人”
     - “状况：噪音过大”
     - “状况：光线过暗”
     - “状况：多种问题”

2. **环境检测逻辑**：
   - **如果开启了人体检测**：
     - 检测不到人 → 状态变为“无人” → 触发蜂鸣器（长音）
   - **如果开启了噪音检测**：
     - 噪音超过阈值 → 状态变为“噪音过大” → 触发蜂鸣器（短音两次）
   - **如果开启了光线检测**：
     - 光线低于阈值 → 状态变为“光线过暗” → 触发蜂鸣器（短音三次）
   - **多种问题同时存在**：
     - 状态变为“多种问题” → 触发蜂鸣器（长音两次）

3. **计时逻辑**：
   - 每秒更新一次剩余时间
   - 时间到0时自动进入完成状态

4. **操作逻辑**：
   - **确认键**：**无特殊功能**（可考虑暂停功能）
   - **返回键**：**无特殊功能**
   - **双键同时按下**：**立即退出到启动界面**

---

## 🎉 **完成状态（STATE_FINISHED）**

1. **界面显示**：
   - 标题：“Done!”
   - 中间显示：“Well Done!”
   - 底部提示：“RESTART” 和 “RESET”

2. **操作逻辑**：
   - **确认键**：重新开始（回到**时间选择界面**）
   - **返回键**：回到**启动界面**
   - **双键同时按下**：**退出到启动界面**

3. **蜂鸣器**：
   - 进入完成状态时播放欢快的完成音（三个连续短音）

---

## 🔄 **状态转换图（简化版）**

```
启动界面
   ↓（确认键）
时间选择
   ↓（确认键）
环境选择
   ↓（确认键）
倒计时学习 →（时间到）→ 完成界面
   ↓（双键同时按）         ↓（确认键→时间选择）
启动界面 ←（双键同时按）←（返回键→启动界面）
```

## ⚠️ **异常处理逻辑**

1. **双键同时按下**：
   - **任何状态**（除了启动界面）→ 直接返回启动界面
   - 启动界面下双键按下无响应

2. **环境警报**：
   - 仅在倒计时状态下触发蜂鸣器
   - 每2秒检测一次，避免频繁报警
   - 环境恢复正常后自动停止报警

3. **状态异常**：
   - 如果进入未知状态，系统自动重置到启动界面

## 🎯 **核心设计特点**

1. **单向流程为主**：启动→选时→选环境→学习→完成
2. **双键退出机制**：在任何操作中都可以快速退出
3. **环境检测可选**：用户可以自由选择开启哪些检测
4. **反馈明确**：
   - 视觉反馈（OLED显示）
   - 听觉反馈（蜂鸣器不同声音）
   - 状态提示（底部文字）
