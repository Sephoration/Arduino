# Focus Cube

Focus Cube 是一个基于 Arduino 兼容开发板和 SSD1306 OLED 的专注计时器。项目提供倒计时、环境检测、蜂鸣器反馈和按键交互，适合制作小型桌面专注提醒设备。

## 功能特性

- 5 到 60 分钟倒计时设置
- OLED 显示启动页、时间选择、环境模式、倒计时和完成界面
- 支持光线、噪音、人体检测等环境状态提示
- 蜂鸣器提供按键反馈、异常提醒和完成提示音
- 双键组合可快速重置当前流程

## 文件结构

```text
Focus_Cube/
├── Focus_Cube.ino            # 主程序入口，负责初始化、按键读取和主循环调度
├── PinDefines.h              # 引脚、阈值和系统常量定义
├── SelfDiscipline.h          # 状态、配置和接口声明
├── SelfDiscipline_page.cpp   # 业务逻辑和状态机处理
├── SelfDiscipline_draw.cpp   # OLED 页面绘制
├── OLED_Display.h            # OLED 显示封装声明
└── OLED_Display.cpp          # OLED 显示封装实现
```

## 运行流程

```text
启动界面
   ↓ 确认键
时间选择
   ↓ 确认键
环境检测选择
   ↓ 确认键
倒计时
   ↓ 时间结束
完成界面
```

在主要流程中，返回键用于切换选项或返回，确认键用于进入下一步。两个按键同时按下时会触发系统重置并返回初始状态。

## 状态说明

| 状态 | 说明 |
|------|------|
| STATE_INIT | 启动界面，等待用户开始 |
| STATE_SELECT_TIME | 选择专注时长 |
| STATE_SELECT_ENV | 选择环境检测模式 |
| STATE_COUNTING | 倒计时运行中，并根据传感器状态提示环境问题 |
| STATE_FINISHED | 倒计时完成，显示完成提示 |

## 环境检测

项目可根据配置读取不同传感器，用于判断当前环境是否适合专注：

- 光线过暗
- 噪音过大
- 未检测到人体
- 多种异常同时存在

检测结果会显示在 OLED 底部，并通过蜂鸣器进行提醒。

## 按键操作

| 操作 | 作用 |
|------|------|
| 确认键 | 开始、确认当前选项或重新开始 |
| 返回/调整键 | 切换时间、切换检测模式或返回初始状态 |
| 双键同时按下 | 重置当前流程 |

## 编译说明

1. 使用 Arduino IDE 打开 `Focus_Cube.ino`。
2. 安装或确认可用以下依赖库：
   - Adafruit GFX Library
   - Adafruit SSD1306
   - Adafruit BusIO
3. 根据 `PinDefines.h` 完成按键、OLED、蜂鸣器和传感器接线。
4. 选择对应开发板和端口后编译上传。

## 可调整参数

常用配置集中在 `PinDefines.h`：

- 按键引脚
- 蜂鸣器引脚
- 传感器引脚
- 最小 / 最大 / 默认专注时间
- 光线、噪音等环境检测阈值

根据实际硬件模块和开发板型号修改这些定义即可。
